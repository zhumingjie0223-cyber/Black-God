Black God 是一款支持多家模型服务商的 AI 助手，将对话、任务技能、长期记忆和本机工具放在同一个 iPhone 应用中。

模型连接
• 配置 Claude、OpenAI、Gemini 及多家 OpenAI 兼容接口
• 根据服务商支持情况获取模型列表，或填写账号可用的模型 ID
• 支持 OpenRouter 账号授权；Kimi、Grok、MiniMax 提供兼容账号授权入口，实际可用性以服务商权限为准
• 可保存多个独立连接，调用费用和额度由你使用的服务商管理

对话与任务
• 流式对话，以及支持模型的原生工具调用
• 本机计算、任务计划、执行记录和操作输出查看
• 管理长期记忆与任务技能，运行内置演练样例
• 内置 Linux 运行环境与工作空间；高级用户可查看和运行命令

数据由你决定
• 使用 Keychain 保存认证凭据
• 对话、记忆、技能和工作文件保存在本机
• 向模型发送内容前，明确展示接收地址与发送范围，并由你开启许可
• 模型请求会发送相关对话、记忆和工具结果；服务商按其政策处理数据

使用须知
在线模型功能需要可用的服务商凭据、网络和相应额度。Claude 官方接入使用 API 密钥，不能将 Claude.ai 订阅直接作为本应用的登录凭据。模型回答和工具结果可能有误，请核验重要内容。Linux 空间预算是应用管理限制，不会增加手机物理容量。

Black God 是独立第三方应用，与所列模型厂商没有隶属关系。当前主要交互语言为简体中文。
