神枢 Black God 是一款自带 API Key 的 iPhone AI 助手，适合问答、写作、编程讨论与分步任务。应用采用深墨绿主题和原生 SwiftUI 界面。

【选择模型服务商】
• 配置 Anthropic、OpenAI、DeepSeek 或 xAI 的 API Key，选择对应模型
• API Key 按服务商分别保存在 iOS Keychain
• AI 请求从设备通过 HTTPS 直接发送至所选服务商

【查看任务进展】
• 将目标规划为步骤，显示任务进度和工具执行轨迹，汇总最终结果
• 停止任务，或从已保存的任务检查点继续执行
• 查看本机任务历史、步骤、输出和运行状态
• 使用系统分享功能交付最终结果
• 手动收藏和删除记忆，为后续任务补充相关上下文
• 流程完成不代表内容已经过事实核查

【清楚管理数据】
• 首次使用每个服务商前，查看数据共享说明并选择是否同意
• AI 功能会向该服务商发送输入、最近对话、相关已收藏记忆及任务上下文；Key 随请求用于身份验证
• 在「我的 → API 配置」撤回服务商共享选择
• 在「我的」查看隐私政策，或清除本机保存的 Key、记忆和运行记录
• 清除本地内容不会删除服务商保存的数据或吊销 API Key
• 无独立应用账号，无内置广告

【使用须知】
需要网络连接及所选服务商的有效 API Key。服务商可能按其账户条款对 API 调用收费；可用模型取决于账户权限和服务状态。应用本身不销售 API 额度或订阅。

界面主要使用简体中文，部分系统与导航文本支持英文。AI 回答可能包含错误，请核对重要结果。神枢为独立客户端，与上述模型服务商无隶属关系。
