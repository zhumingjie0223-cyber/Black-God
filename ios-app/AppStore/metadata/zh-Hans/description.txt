神枢 Black God 是一款纯客户端的 AI 助手。你自带模型服务商的 API Key，App 直接连接该服务商的官方接口，中间没有任何第三方服务器，所有数据只保存在你的 iPhone 上。

【零后端，直连模型】
• 填入你自己的 API Key，即可直接使用 Anthropic（Claude）、OpenAI（GPT）、DeepSeek、xAI（Grok）的模型
• 请求从你的设备直达你所选服务商的官方接口，不经过我们的任何服务器
• 支持流式输出，回复逐字实时呈现
• 每个服务商的 Key 分开保存、自由切换；费用按你自己的 API 账户结算，App 本身不收取任何订阅费

【不只是聊天：会规划、会执行、会自查】
• 复杂任务自动拆成步骤，逐步执行、逐步验证，失败自动重新规划
• 内置工具总线：时间、计算、读写本机文件；写入与命令类操作必须经你确认才执行
• 「神枢监测」页展示任务成功率、验证率、恢复率，全部在本机统计

【隐私优先，本地存储】
• API Key 使用 iOS 系统 Keychain 加密保存，仅本机可读
• 记忆、运行记录与工具产物全部存储在设备本地，不上传、不同步、不分析
• 无账号、无注册、无埋点、无广告
• 「我的」页一键清除全部数据，删得干干净净

【专为 iPhone 打磨】
• 深色主题 + 翡翠绿点缀的沉浸式界面，阅读舒适
• 原生 SwiftUI 构建，流畅顺滑，支持触感反馈
• 支持快捷指令（Shortcuts），可通过 Siri 直接发起对话
• 简体中文与英文双语界面，跟随系统语言自动切换

【适合谁】
• 已经拥有模型服务商 API Key、希望在手机上随时随地使用模型的开发者与创作者
• 重视隐私、不希望对话内容经过任何第三方中转的用户
• 想要一个干净、无广告、无订阅的 AI 工具的人

【使用须知】
• 使用本 App 需要你自行在所选服务商官网申请 API Key（如 console.anthropic.com、platform.openai.com）
• 模型调用产生的费用由该服务商按你的 API 账户直接计费，与本 App 无关
• 本 App 为独立第三方客户端，与 Anthropic、OpenAI、DeepSeek、xAI 均无隶属关系
