神枢 Black God 是一款纯客户端的 AI 对话助手。你自带 Anthropic API Key，App 直接连接模型服务，中间没有任何第三方服务器，所有对话记录只保存在你的 iPhone 上。

【零后端，直连模型】
• 填入你自己的 Anthropic API Key，即可直接与 Claude 系列模型对话
• 请求从你的设备直达 Anthropic 官方接口，不经过我们的任何服务器
• 支持流式输出，回复逐字实时呈现
• 可自由切换模型，费用按你自己的 API 账户结算，App 本身不收取任何订阅费

【隐私优先，本地存储】
• API Key 使用 iOS 系统 Keychain 加密保存，仅本机可读
• 对话历史全部存储在设备本地，不上传、不同步、不分析
• 无账号、无注册、无埋点、无广告
• 随时可在设置中一键清除全部数据

【专为 iPhone 打磨】
• 深色主题 + 金色点缀的沉浸式界面，阅读舒适
• 原生 SwiftUI 构建，流畅顺滑，支持触感反馈
• 支持快捷指令（Shortcuts），可通过 Siri 直接发起对话
• 简体中文与英文双语界面，跟随系统语言自动切换

【适合谁】
• 已经拥有 Anthropic API Key、希望在手机上随时随地使用模型的开发者与创作者
• 重视隐私、不希望对话内容经过任何第三方中转的用户
• 想要一个干净、无广告、无订阅的 AI 对话工具的人

【使用须知】
• 使用本 App 需要你自行在 console.anthropic.com 申请 Anthropic API Key
• 模型调用产生的费用由 Anthropic 按你的 API 账户直接计费，与本 App 无关
• 本 App 为独立第三方客户端，与 Anthropic 公司无隶属关系

神枢，让你的 AI 对话真正属于你自己。
