Black God combines AI conversations, task skills, curated memory and local tools on iPhone.

CONNECT YOUR MODELS
Configure Claude, OpenAI, Gemini and OpenAI-compatible providers. Discover available models where supported, or enter a model ID supplied by your provider. Save separate connections for different accounts.

OpenRouter account authorization is available. Kimi, Grok and MiniMax compatibility sign-in follows public CLI authorization flows; availability depends on provider permissions and policies. Provider accounts manage their own usage and billing.

CHAT AND WORK
Use streaming conversations and native tool calls with supported models. Run local calculations, inspect task plans and execution output, manage memories and skills, and run built-in practice examples. An embedded Linux environment provides a local workspace and advanced command controls.

CONTROL DATA SHARING
Credentials are stored in Keychain. Conversations, memories, skills and workspace files are stored locally. Before model content is sent, the connection screen explains its destination and data scope and asks for explicit permission. Requests may include conversation content, selected memories and tool results. Providers handle transmitted data under their own policies.

Online model features require working provider credentials, network access and available quota. Direct Claude access uses an API key, not a Claude.ai subscription login. AI output and tool results can be incorrect; verify important results. Storage budgets do not increase physical device capacity.

Black God is an independent third-party app with no affiliation to the listed model providers. The current interface is primarily Simplified Chinese.
