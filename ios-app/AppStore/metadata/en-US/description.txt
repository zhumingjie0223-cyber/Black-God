Black God Nexus is an iPhone AI assistant for questions, writing, coding discussions, and tasks with multiple steps. Bring your own provider API key and use a native SwiftUI interface with a deep green theme.

CHOOSE YOUR PROVIDER
• Configure an API key for Anthropic, OpenAI, DeepSeek, or xAI and select a model
• Store keys separately by provider in iOS Keychain
• Send AI requests directly from your device to the selected provider over HTTPS

FOLLOW TASK PROGRESS
• Plan goals as steps, follow task progress and tool activity, and receive a final result
• Stop a task or continue from a saved checkpoint
• Review local task history, steps, output, and run status
• Share final results using the system share sheet
• Manually save and delete memory to provide context for later tasks
• A completed workflow does not mean the content has been fact-checked

MANAGE YOUR DATA
• Review sharing information and choose whether to allow each provider before its first use
• AI requests send your input, recent conversation messages, relevant saved memory, and task context to that provider; your key authenticates requests
• Withdraw sharing under Me → API configuration
• Read the privacy policy or clear locally saved keys, memory, and run records from Me
• Clearing local data does not erase provider-held data or revoke API keys
• No separate app account and no embedded ads

BEFORE YOU START
An internet connection and a valid API key for your chosen provider are required. The provider may charge for API usage under your account terms. Model availability depends on your account permissions and service status. The app does not sell API credits or subscriptions.

The interface is primarily in Simplified Chinese, with some English system and navigation text. AI responses may contain errors; verify important results. Black God Nexus is an independent client and is not affiliated with the model providers listed above.
