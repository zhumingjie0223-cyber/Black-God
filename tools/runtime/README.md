# Reproducible embedded Linux build

Run `make prepare-runtime` on an Apple Silicon Mac with Xcode, ninja, llvm, libarchive, pkg-config, Python 3. Meson 1.9.2 is installed in a project-local virtual environment.

Source: vendor/ish, OpenMinis/ish-arm64 commit 3f6384c70eefd1a370f121d3492a5f21f7767df9, imported using git archive. No user checkout changes or built binaries were imported. The host-side executor is separately attributed in THIRD_PARTY.md.

Outputs (gitignored): .runtime-build, .runtime-build-tools, ios-app/Runtime/Libs/{iphoneos,iphonesimulator}, ios-app/Runtime/AlpineRootfs. All are regenerated by this script. The rootfs archive comes from the official Alpine CDN and must match the SHA256 pinned in build.py. Device and simulator libraries are independently cross-compiled; device .a files are not reused for simulator linking.

After upgrading Xcode or the source revision, remove the generated .runtime-build directories and rebuild. Do not delete a user's installed runtime data as part of a source upgrade. A rootfs upgrade needs a new runtime directory and an explicit data migration policy.

Tests use a real simulator guest kernel. A physical iPhone performance and lifecycle test is still required before release. The current rootfs is a pinned integration baseline and must undergo a package/security update review before production distribution.
