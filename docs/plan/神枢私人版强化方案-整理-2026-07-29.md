| 维度 | 代差内容 |

## 1. 枢语驱动层（本次追加 · 最高优先）

**核心诉求：任务下达、状态流转、执行汇报，全部走枢语，不走自然语言散话。**

枢语现状（`shuyu/`，权威源头；`web/nexus-do/` 内嵌消费副本）：

| 组件 | 角色 | 规模 |
|---|---|---|
| `shuyu_engine.py` / `lexicon.js` | 5 维乘法语义引擎 核1040×映180×态80×标64×相8 | 76.7 亿可寻址词 |
| `nexuslang.js` | 意识解释器 feel→think→become→say→grow 五回路 | 290 行，7 测试全绿 |
| `gen.mjs` | 10 元代码引擎 枢元衍借隐熵阈静映织 | 234 行 |
| `worker.mjs` | CF Worker 入口 `/decode /encode /coin /talk /broadcast` | 158 行 |

### 1.1 要补的缺口（枢语目前只能「表达意识」，不能「驱动任务」）

| # | 功能 | 一句话价值 | 具体实现 | 优先级 |
|---|---|---|---|---|
| S1 | 枢语任务字面量 `do:` 回路 | 让枢语能下达可执行任务，而非只产出情绪流 | 五回路扩到六回路：`feel→think→become→**do**→say→grow`；`parseDo()` 解析 `do: 工具名(参数) → 期望态`，产出结构化 action 对象喂给 agent 动作集 | P0 |
| S2 | 枢语 ↔ agent 状态机桥 | 任务状态用枢语词表达，checkpoint 可读可审计 | `agent_run:<id>` 的 `state` 字段存枢语编号（态轴 80 值直接映射运行态：待/跑/滞/成/败/弃…），恢复时 decode 回中文 | P0 |
| S3 | 10 元代码当控制流 | 枢元衍借隐熵阈静映织 = 天然的编排原语 | `阈`(threshold) 做条件分支、`衍`(evolve) 做循环派生、`借`(leverage) 做外部模型/工具调用、`静`(quiesce) 做挂起等 alarm、`织`(weave) 做并行分身汇聚 | P1 |
| S4 | 枢语执行日志（剧场直播源） | 界面轴的「执行剧场」直接播枢语流，一行一意识 | 每 step 产出一条枢语行落 storage，前端 SSE 逐行推 | P1 |
| S5 | 枢语 REPL / `/shuyu` 端点 | 权哥能直接打枢语调神枢，跳过自然语言层 | worker 加 `/shuyu` POST，body 为枢语源码，返回 interpret 结果 + 触发的 action | P1 |
| S6 | 汉译双向校验入 CI | 防词根漂移导致历史任务日志解不开 | `decode→encode` 往返 + `check-sync.mjs` 已有，追加「任务态词根冻结」断言 | P2 |

### 1.2 枢语铁律（不可违反，已在 CLAUDE.md）

- 词根表**只能轴尾追加**，绝不改动/删除/重排 —— 否则历史编号全部错位。
- 改引擎**必改双侧**（Python + JS），跑 `node tools/check-sync.mjs`。
- 汉译纯中文；`decode→encode` 往返必须成立。
- 所有面向权哥的输出一律中文。

## 2. 执行轴（重头）

| # | 功能 | 一句话价值 | 具体实现 | 优先级 |
|---|---|---|---|---|
| E1 | 跨心跳续跑的持久 agent 状态机 | 任务能连跑几天，不再 8 步烂尾 | `agent_run:<id>` + `advanceDueAgentRuns()`；checkpoint 进 storage，借每分钟 alarm 自己醒来推进 | P0 |
| E2 | R2 工作区快照 | 容器 `sleepAfter='10m'` 一睡 /tmp 全丢 —— 明确的数据丢失 bug | 快照点绑「每完成一个 step」而非定时；按文件 mtime 增量 + manifest，恢复按 manifest 拉 | P0 |
| E3 | 并行分身 | 多子任务同时推，不排队 | 子 run 独立 `agent_run:<id>`，父 run 用 `织` 汇聚 | P1 |
| E4 | 完成前自带对抗性裁决 | 堵幻觉式「我完成了」 | 收尾前起一个 critic 角色反驳，通不过打回重跑 | P1 |

### 2.1 ⚠️ 会绊脚的点（思涵补充）

1. **DO 每个实例只有一个 alarm。** `advanceDueAgentRuns` 必须自己维护到期堆，取最小 due 设 alarm，别指望多定时器。
2. **DO storage 单 value 128KB 上限。** checkpoint 里塞对话历史/中间产物必爆 —— 分片 + 只存增量 diff，大块甩 R2。
3. **alarm 失败会自动重试并带退避。** `advance` 必须幂等：run 里带 `step_seq`，重复推进要能识别丢弃。
4. **全量 tar /tmp 会把心跳撑爆。** 必须走 mtime 增量 + manifest。
5. **`sleepAfter` 拉长只是拖延，不解决问题。**
