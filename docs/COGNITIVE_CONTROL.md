# 神枢：可验证的认知能力与改进边界

本轮实现给定线性因果模型的干预计算、无环任务依赖/时长下界、本机图片文字识别、带来源的知识候选与模型工具权限审计。不是通用智能或主观意识的证明，也没有训练基础模型权重。

## 实际运行路径

ChatViewModel 将三个新工具注册到文本与原生工具回合：causal_model、dependency_plan、knowledge_propose。原生参数定义在 NexusNativeAgent 中。因果和依赖工具也供 AppIntents 使用。聊天与 AppIntents 的模型工具调用通过 NexusToolRegistry 的治理入口，失败或撤销后不向模型返回过期成功结果。高级终端的用户直接操作与固定内置技能演练仍使用既有执行日志和停止机制，不受这项“模型工具权限”开关控制。

模型工具默认只允许本地分析与候选记录。工作区授权明确包含可能联网的脚本，30分钟后到期，重启失效；不宣称独立的网络隔离等级。撤销中止当前 guest，并阻止后续调用。模型请求的数据发送许可单独管理，撤销工具权限不能撤回已发网络请求或已发生写入。

## 知识变更

模型只能提交候选，无法调用确认、替换、恢复或授权操作。用户核对来源后启用。同主题替换须明确指出旧记录；不同主题的已启用资料必须逐项保持不变。历史版本保留，恢复也重新成为候选。确认或撤回资料会停止正在使用旧资料的聊天任务。仅当前启用清单进入新请求。

这属于外部记忆管理，不是持续训练；保留检查只证明记录未被意外删除，不能证明事实正确或解决模型权重的灾难性遗忘。冲突检查按主题规范化匹配，不能保证检测所有语义矛盾。最多40条启用资料、累计200个版本；满额时拒绝新增，不自动遗忘。

## 图片观察

PhotosPicker 让用户自行选择图片。Apple Vision 在本机执行 OCR，限制20MB输入并缩小至最长边2048像素。提取内容、图片SHA-256及时间写入可编辑表单；先核对再保存候选，原图不发送给模型。OCR不等于场景理解。启用后的文字资料及来源可以随后续获准模型请求发送。

## 审计与失败处理

治理文件原子保存事件和记录。工具开始先落盘；写入失败不执行。审计只保存调用编号、工具名和稳定排序参数的SHA-256，不存原始参数；哈希不等于匿名化。撤销保存失败仍在内存立即失效并停止受管工具。重启把无结束事件的调用标记 interrupted，不推断它没有副作用。审计最多2000条，满额停止，不自动覆盖；尚未实现审计归档轮转。

## 自我改进和未实现范围

现有计划/执行/复核与技能演练继续可用，但模型自评不等于独立验收。当前新增内容只允许提出知识候选，无自动激活、改写自身代码、扩大权限或权重更新工具。

仍需工作：真实模型账号端到端验收；更广泛的因果/规划评测和资源约束规划；语音转写、通用图像理解、机器人适配与真实实验设备；可信实验数据采集与独立科学结论验证。没有硬件和真实实验，不伪造实验结果。

商店发布需更新公共隐私政策到这一版本，并完成既有账号/真机/审核条件。此前build5 GitHub草稿的附件上传失败，目标必须固定为07f5f2d794e485873abc828ec3da614e93338453，不能把后续分支提交误标为build5。


## 构建7：自我状态连续性

NexusSelfContinuity保留稳定本地记录编号、目标、执行阶段、工具返回状态、公开自评、疑问和建议下一步。由ChatViewModel实际任务生命周期自动写入，工具结果由检查点去重采集，不保存原始工具参数/输出。self_reflect仅记录当前运行绑定的公开摘要，不能确认知识、提升权限、改变完成状态或触发旧计划。它不是内部思维链或主观意识。answered只表示答复生成，工具成功和模型自评均不等于独立验收。

最近120条滚动保存，显示移除数；后续请求最多注入最近6条，并标明不可信历史参考、当前指令与授权优先。不是完整无限记忆。按事件更新，无后台计时推理或额外模型调用。进程重启将未结束任务标记中断且不续跑。暂停/清空取消当前聊天，旧run回调不能恢复内容；清空轮换本地记录编号，只清此文件，不清聊天和任务检查点。写入失败停用记录功能，不伪造连续历史；主聊天可继续但不能宣称此记录可用。损坏文件保留，不自动覆盖修复。

界面入口为“我的 → 神枢成长 → 查看自我状态流”。只有任务级身份连续性，没有独立意识形态、主观体验或自发价值目标。记录的模型判断不自动变成真理。此轮未扩展AppIntents的状态流，也未开放机器人或后台自主控制。
