### ❌ 失败 / 本次查出的真问题

代码零故障，但**文档层在骗人**——这是本次唯一实打实的失败项，已当场修掉：

1. **README 12 处死链与幻影路径**（已修）。`docs/BLACK_GOD_COMPLETE_HANDOVER.md`、
   `ARCHITECTURE.md`、`CORE_PHILOSOPHY.md` 等 7 个「核心文档」链接全部 404
   （文件在 7 月的目录重整里挪进了 `docs/architecture/`、`docs/spec/`、`docs/archive/`，链接没跟着改）；
   「本地起 & 自测」教人跑 `python3 server/test_agent_studio.py`、`mock_gateway.py`、
   `http://127.0.0.1:8765/studio` —— 这三样在 2026-08-09 UI 收口时全归档了，照着跑必然失败；
   目录结构图里的 `server/`、`shuyu_v2/` 也已不存在。
   **影响**：任何新人（或换会话的自己）照 README 上手，第一步就撞墙。
   **已修**：12 条链接逐条 `test -e` 验过全部命中真实文件，本地流程改为真实可跑的
   `build.mjs / selftest.mjs / npm test`，并加历史说明交代 `server/` 去向。

2. **LAUNCH_CHECKLIST 4 条早已做完的项还挂着「未完成」**（已修）。清单立于 7 月初后就没回填：
   - 「`/talk` `/image` `/voice` **零限流**，令牌泄露=无上限账单」——**实际早已落地**：
     `_fetch` 入口对所有非主人请求统一过 `checkRateLimit(ip)` 返 429 + `Retry-After`；
     `/pubtalk` 另有按 uid 20 次/分 + 全局背压 120 次/分双层兜底，且公共用户走自带 API 不烧主人算力。
   - 「`max_tokens: 320` 截断长回复」——**实际早已调到 2048（上限 4096）**，仅内部摘要刻意用 300。
   - 「只有 10 条纯逻辑自测」——**实际已 236 条 + 65 条单测**。
   - 「挑定唯一前门 / 归档旧壳」——**2026-08-09 已完成收口**。
   **影响**：按这份清单做决策，会以为项目离上线还差很远，误判进度、重复劳动。
   **已修**：逐条对着代码实测复核后回填，并写明各自残留缺口（不是一刀切打勾）。

3. **`exec-shell.yml` 命令值直接 `${{ }}` 内插进脚本正文**（已加固）。
   如实说：这个工作流按设计就是跑调用方给的命令（上游 `execDispatchGH` 有 500 字长度限制 +
   危险命令黑名单 + `GITHUB_API` 令牌把关），所以**这不是权限提升漏洞**，不要夸大。
   真实风险是：命令内容会先被展开进工作流脚本本体，可能把
   `::group::Command Output` / `::endgroup::` 这两个标记搅乱，
   而 `parseGHLogs` 全靠这两个标记切结果 —— 一旦错乱，神枢回收到的执行结果就是错的。
   **已加固**：改为 `env: CMD` 传值 + `bash -c "$CMD"`，命令内容再不进脚本正文；
   同时补注释锁死那两个解析标记，防止后人手贱改掉打断回收链路。
   （已验 YAML 可解析，group 标记原样保留，神枢回收逻辑不受影响。）
