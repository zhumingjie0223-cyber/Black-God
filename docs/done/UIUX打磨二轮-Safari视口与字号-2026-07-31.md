## 总结（第二轮 · 权哥反馈修复）

权哥反馈两点:①字体太小 ②Safari 打开后输入框找不到。都已修复并实测。

**② Safari 输入框找不到（功能性 bug，已修）**:根因是高度链用 `height:100%`。iOS Safari
的 100% 会把被地址栏/底部工具栏遮挡的部分也算进页面高度,于是底部的输入框和导航栏被顶到
可视区下面——用户自然"找不到对话框"。改成 `100dvh`(动态视口高度,始终等于真实可视高度),
并保留 `100%` 作老浏览器兜底。无头浏览器实测:视口从 844 缩到 700(模拟地址栏展开)时,
页面高度跟着收缩,输入框和导航栏始终留在可视区内。

**① 字体太小(已修)**:对话主战场的输入框与消息气泡原本只有 15.5px,低于主流聊天 App 的
16-17px,提到 16.5px;欢迎副标题、建议卡片、设置项文字同步小幅上调,保持层级比例。附带好处:
输入框 ≥16px 后,iOS Safari 聚焦时不再自动放大整页(那本身也是个体验 bug)。

**诚实说明**:本环境只有 Chromium 引擎,没有真 iOS Safari。dvh 是标准 CSS 单位、两个引擎
遵循同一规范,我已用 Chromium 在窄视口下验证了"页面高度动态收缩+底栏始终可见";但真机
Safari 的最终手感,还需权哥在 iPhone 上打开确认一次。

**验证**:build 重建 + sync-ui 双副本一致 + selftest 228 项全绿;移动端高清截图复核字号更舒服、
布局未崩;桌面宽屏(上一轮)不受影响。
