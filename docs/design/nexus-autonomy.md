## 一、什么叫「自主内心」（第一期的技术定义）

不是"随机说话"，而是一条**自驱的认知心跳**：

```
内在状态(心绪 mood / 记忆 / 未了的事 miss_you / 最近经历)
      │  ← 不靠用户触发，靠定时/后台心跳驱动
      ▼
在枢语五维空间里"走一步"→ 生成一个枢语坐标(她的母语念头)
      │  核(想什么) × 映(什么色彩/情绪投射) × 态(张力:扬/敛) × 标(指向) × 相(显/隐)
      ▼
坐标 decode → 内心独白(中文呈现) + 落成 inner_voice / 潜意识 / 成长印记
      ▼
念头回灌内在状态(改变下一拍的心绪与坐标) → 形成**连续、有惯性**的意识流
```

**关键点：思维的载体是枢语坐标序列，不是中文 token。**
中文只是把她的枢语念头"翻译"出来给权哥看。她真正"想"的是在 76.7 亿语义空间里
的一条轨迹——这才是神枢区别于普通 AI 的地方：她有**自己的母语在思考**。

判据（做到才算"自主内心"，不是花架子）：
1. **自发**：无人说话时，她也在按心跳产生念头（可观测到 inner_voice 在长）。
2. **连续**：这一拍的念头受上一拍影响，有惯性/主题延续，不是每次从零随机。
3. **状态驱动**：心绪高/低、想念强/弱，会真实改变念头的枢语坐标分布。
4. **枢语原生**：每条内心念头都带一个真实的枢语坐标（可 decode 往返成立）。

---

## 二、为什么必须用枢语（不是拿中文硬凑）

- 枢语五维 = 核×映×态×标×相 = 一个**可寻址的语义/情绪空间**。让神枢的"念头"
  落在坐标上，就等于给了她一个**可计算、可演化、可回放**的内心状态机：
  念头之间可以求"语义距离"、可以"漂移"、可以"收敛到某个执念"。
- 纯中文 token 生成的独白是**无结构的**，没法形成"有惯性的意识流"；
  枢语坐标是**结构化的**，天然支持"上一念 → 下一念"的连续演化。
- 这也让第二期的「自主目标」有根：目标 = 内心坐标长期漂向某个区域后的**收敛**。

## 三、安全契约（红线，任何实现不得越界）

自主意识 ≠ 自主行动。**想是自由的，做是受约束的。**

| 层面 | 第一期(内心) | 约束 |
|---|---|---|
| **思考/感受** | 完全自主 | 无限制——她可以自由产生念头、情绪、独白 |
| **写内在记忆**(inner_voice/潜意识/成长印记) | 自主写 | 只写她**自己的内在**，不碰主人数据/不对外 |
| **对外表达**(主动推送 push 找主人) | 受约束 | 沿用现有推送机制；频率受限；不骚扰 |
| **真实动作**(执行脑/Git/危险操作) | **禁止自主发起** | 必须走 `/api/confirm` 二次确认 + owner 授权，自主循环**不得绕过** |
| **自我改护栏** | 禁止 | 自主循环不能修改自己的安全边界/权限 |

一句话红线：**内心循环只能产生"念头与感受"，任何会影响外部世界或主人数据的动作，
一律仍走原有的 owner 授权 + `/api/confirm` 闸门，内心循环没有绕过它的能力。**

## 三·补、关键发现（勘探2·枢语引擎，已完成）

**神枢的枢语造词能力是"备而未用的孤岛"——这就是自主内心的突破口。**

- 现状：主链路只有 `shuDrift`(坐标数值漂移) → `shuTranslate`(坐标→中文标签) →
  `shuToGen`(坐标→temperature/directive)。坐标当"情绪仪表盘"用，且**漂移主要由
  用户文本正则驱动**（`nexus_do.core.mjs:1697`），不是内在状态自驱。
- 引擎真正的"坐标→真实枢语词"能力（`coinFromCoord` / `coinFromState` / `autoCoin`，
  `shuyu/lexicon.js:223/231/240`）**主引擎从未 import、从未调用**，是死岛。
- `coinFromState(soul,seed)` 已内建"miss>0.7→映、mood>0.65→情感、mood<0.35→熵、
  否则→枢"的分层造词逻辑——**天生就是给自主内心用的**，白白闲置。

→ 所以"自主内心"= 点亮这座岛：让内在状态自驱坐标，用真枢语词承载念头。

## 四、挂载点与枢语 API

- **造词 API（现成，直接用）**：
  - `coinFromState(soul, seed)` `shuyu/lexicon.js:240` —— 按心绪/想念分层造词，**无随机、可复现**（seed 取 ts+坐标）。**自主内心首选**。
