# 神枢设计参考总文档

## 一、沙箱选型

### 1.1 市场现状（15家对比）

**隔离强度梯度**：
- **KVM虚拟化**：Devin/Claude官方（完整VM）
- **容器**：Lovable/Replit/Manus/Grok/Gemini（cgroups隔离）
- **浏览器沙箱**：Bolt.new（WebAssembly）> v0（iframe+V8 Isolate）
- **用户态**：Minis（x86模拟）
- **零隔离**：Cline/Cursor/Aider（直接执行）

**启动速度**：Cursor/Cline/Aider(0ms) > Bolt.new(<100ms) > v0(1-2s) > Replit/Lovable(2-5s) > Manus(5-10s) > Devin(30-60s)

**成本**：Bolt.new/Aider/Cursor(零) > v0(边缘计算) > Replit(共享容器) > Lovable(按需) > Manus/Devin(持久VM)

### 1.2 关键实现（8家深度）

| 产品 | 技术栈 | 核心特性 | 资源限制 |
|------|--------|----------|----------|
| **Bolt.new** | WASM+MEMFS+ServiceWorker | Node.js运行时浏览器编译，`<boltAction>`标签解析 | 无后端成本，<100ms冷启动 |
| **Lovable** | AWS Firecracker+cgroupsv2 | 异步Job(POST+轮询)，iptables白名单 | 2核/2GB/10GB，5分钟超时 |
| **Devin** | KVM+EBS+VNC | str_replace_editor精确行号，xdotool computer_use | 4核/8GB，持久化 |
| **Replit** | NixOS容器+WebSocket | replit.nix声明式依赖，RPC流式输出 | 共享资源池 |
| **v0** | Vercel Edge V8 Isolate | iframe sandbox+CSP | 30秒/50MB/100次/日 |
| **Gemini** | gVisor runsc | zero-network策略，function calling触发 | 60秒硬中断/1GB |
| **Claude官方** | Firecracker+断网 | Artifacts用iframe隔离 | 30秒/1GB，完全离线 |
| **Aider** | 零沙箱+Git | 每次修改自动commit，SEARCH/REPLACE块 | 无限制 |

**来源**：Bolt.new官网技术文档，Lovable API文档，Devin工具列表，Aider开源代码

### 1.3 神枢方案

**双轨架构**：
- **主轨（前端）**：WebContainers（StackBlitz开源）
  - 浏览器内Node.js WASM运行时
  - 内存虚拟文件系统（MEMFS）
  - 支持npm/Git/Vite/Webpack
  - 零后端成本，毫秒启动
  - 限制：无系统命令/Python
  
- **辅轨（云端）**：Docker+gVisor
  - Python 3.11-slim镜像
  - 2核/4GB/15秒超时/512MB输出
  - 只读文件系统（除/tmp）
  - 网络白名单（PyPI/GitHub）
  - 执行后立即销毁

**决策理由**（来源：Bolt.new生产验证）：
- 70%场景前端完成（JS/TS/前端框架）
- 成本前端免费+云端按需
- 启动速度<100ms vs 容器2-5秒
- 安全审批触发：`rm -rf`类/curl外部/写入系统目录

## 二、工具体系

### 2.4 联网搜索

**意图识别路由**（来源：Gemini grounding机制）：
- 实时信息 → web_search（Brave API）
- 技术文档 → grounding_search（溯源）
- 舆情监控 → x_search（Grok API）

**触发条件**：
- 显式："最新"/"现在"/"今天"
- 隐式：知识截止日期后
- 主动建议：检测到过时信息

**Grounding机制**（Gemini数据）：
1. 结果注入Prompt（带引用编号）
2. 前端跳转源链接
3. 效果：减少幻觉40%+

### 2.5 代码执行流程

**轨道1：WebContainers（JS/TS）**
- 支持：npm/Vite/Webpack/SQLite WASM
- 持久化：IndexedDB
- 网络：fetch白名单
- 限制：无系统命令/Python

**轨道2：云端容器（Python/Shell）**
```yaml
镜像: python:3.11-slim
资源: 2核/4GB/15秒/512MB
安全:
  - 文件系统只读（除/tmp）
  - 网络白名单（PyPI/GitHub）
  - 禁止eval()/exec()
  - 执行后立即销毁
```

**审批触发**（来源：Cline审批弹窗）：
- `rm -rf`类命令
- curl外部API
- 写入/etc /usr系统目录

**执行流程**：
语言检测 → 分轨 → P0安全审批 → 执行 → 流式返回（最多3次重试）

### 2.6 路线图

| 阶段 | 周期 | 工具 | 验证场景 |
|------|------|------|----------|
| **Phase1 MVP** | 2周 | str_replace_editor + read/write_file + codebase_search + WebContainers + Brave API | React Todo App需求→代码→预览 |
| **Phase2 增强** | 4周 | Docker沙箱 + git集成 + LSP + Puppeteer + 审批系统 | CSV数据分析自动化 |
| **Phase3 差异化** | 6周 | computer_use + artifacts + MCP + grounding + image_generation | SaaS应用端到端交付 |

### 2.7 风险矩阵

| 风险 | 等级 | 缓解措施 | 来源 |
|------|------|----------|------|
| 沙箱逃逸 | 高 | gVisor二次隔离+只读文件系统 | Gemini架构 |
| 成本失控 | 中 | 70%前端化+15秒超时 | Bolt.new数据 |
| 恶意代码 | 高 | 审批+白名单 | Cline模式 |
| 数据泄露 | 高 | 网络隔离+输出审查 | Claude官方 |
| Token爆炸 | 中 | 按行读取+智能裁剪 | Cursor实践 |
