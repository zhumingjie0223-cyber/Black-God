# Black God AI · 神枢 Nexus 唯一真相定义

## 产品身份

- **Black God AI**：面向用户的 AI 助手产品。
- **神枢 Nexus**：Black God AI 的任务运行时与协调中枢。
- **枢语 Shuyu**：神枢使用的结构化意图与动作协议。
- **模型 Provider**：可替换的推理引擎，不等同于神枢。
- **iSH / 工具层**：执行命令、文件、媒体和本地任务。

## 运行闭环

```text
用户目标 → 神枢解析 → 枢语意图 → 模型规划 → 工具执行 → 实时事件 → 结果交付
```

## 神枢职责

1. 管理 session、run 与生命周期。
2. 路由模型与工具。
3. 将自然语言转换为结构化任务。
4. 执行并回流工具结果。
5. 输出文本、终端流、文件和其他产物。
6. 管理取消、暂停、失败、重试和用量。

## 状态机

`idle → planning → runningTool / streaming → completed`

异常分支：`waitingForInput / paused / failed / cancelled`。

## 枢语职责

枢语是协议，不是人物角色。它负责意图、动作、状态和结果标签；模型负责推理，神枢负责协调，工具负责执行。

## 明确排除

现行产品不包含人物人格、主人关系、情感依附、灵魂状态或角色化称呼。历史文档中的此类内容不属于当前产品契约。
