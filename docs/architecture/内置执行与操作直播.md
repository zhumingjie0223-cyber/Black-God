# 内置执行与操作直播

日期：2026-09-09。

## 用户体验

用户直接输入“统计这段文字”或“把商品价格整理成CSV”等自然语言目标。Black God 使用模型生成具体工具参数，在内置的 iSH/Alpine 工作区执行，再依据实际结果答复。无需单独安装 iSH，也无需用户输入脚本。

工具页提供自然语言任务入口和示例，与聊天使用同一个 ChatViewModel。运行中再次进入工具页可回到当前任务，不另外启动重复任务。手动终端收进高级工具。新安装默认启用工作区执行；已有明确关闭的设置保持关闭。关闭时停止当前命令和聊天任务，执行前再次检查开关。

## 小直播窗口

聊天标题下展示“操作直播”：

- 当前实际步骤与事件时间；不展示模型隐式推理。
- Black God 传给工具的操作命令。
- iSH 逐行标准输出与错误输出，命令结束前即更新。无换行的最后一段在流关闭时输出；无数据时保持等待。
- 每次工具的实际结果，包括退出码、错误或成功状态；复核进度另外显示。
- 进行中可一键停止，可收起或展开。结束后保留本轮窗口并收起；新任务清空旧过程。

这是应用内的命令行操作过程，不是其他手机应用的屏幕录像或浏览器画面。目前未实现浏览器视觉操作，工作区文件的通用导入/导出与预览入口也尚需完善。

## 实现与边界

NexusLiveExecution 管理可观察事件，NexusLiveExecutionView 显示窗口。聊天由引擎 onEvent / onCheckpoint 驱动步骤和工具结果；NexusLinuxTool 将 onStart / onOutput 连接到 NexusLinuxRuntime 的真实 ObjC 行回调。手动终端复用同一窗口。

行回调在主线程交付，操作ID与任务ID过滤旧回调。停止或结束后的直播对象拒绝新内容。checkpoint重复推送不会重复显示同一工具证据。

为限制输出洪峰，ObjC每条命令最多排入200次主队列更新，第200条显示截断提示；长行展示上限1200字符，完整stdout/stderr收集仍遵守原有每路256 KiB限制。界面最多60条/16000字符，较早内容移除并提示。已知当前连接密钥在直播对象中脱敏；直播不单独落盘，也不是完整审计日志。

手动终端属于独立工作区，不能用它的截图证明真实模型已完成任务。自动化模型闭环使用可控模拟模型，工具和iSH实际执行；真实服务商模型效果必须另外验收。
