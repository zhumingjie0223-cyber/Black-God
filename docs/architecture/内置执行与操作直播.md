# 内置执行与操作直播

更新：2026-09-24。本文描述尚未发布的本地开发版，不能作为 App Store 1.2.1 已具备这些界面的证明。

## 用户体验

用户直接输入“统计这段文字”或“把商品价格整理成CSV”等自然语言目标。Black God 使用模型生成具体工具参数，在内置的 iSH/Alpine 工作区执行，再依据实际结果答复。无需单独安装 iSH，也无需用户输入脚本。

应用保留“对话、创作、监测、我的”四个主页面，不再设置独立工具页。自然语言任务从对话发起；执行权限、运行空间、枢语与手动终端位于“我的 → 高级设置”。新安装默认启用工作区执行；已有明确关闭的设置保持关闭。关闭时停止当前命令和聊天任务，执行前再次检查开关。

对话空态去掉大段说明与示例卡，使用动态绿光光球、悬浮输入栏与导航，原有黑绿主色值不变。消息正文保留全文；执行计划、详细过程与依据按需查看，避免挤占对话。光效是装饰，不显示模型内部推理，不代表执行进度或模型能力提升。

## 小直播窗口

普通任务在聊天标题下只显示一行实际运行状态和停止按钮。收到工具接受的 Shell 命令后，自动显示约 160 pt 高的“工具直播”小窗口。工作区准备、容量检查和执行阶段按真实事件更新；高度会随动态字体调整：

- 显示 Black God 实际传给工具的命令，以及当前执行状态。
- iSH 逐行标准输出与错误输出，命令结束前即更新。无换行的最后一段在流关闭时输出；无数据时保持等待。
- 显示工具返回的实际结果，包括退出码、错误或成功状态；不伪造百分比或操作画面。
- 进行中可一键停止，点击窗口标题可展开任务详情。任务结束后收起小直播，保留的记录可从顶部“对话管理”菜单重新打开；新任务清空同类旧过程。

聊天的“任务详情”包含计划与保留的执行记录；“演练记录”单独显示技能演练，不混入聊天计划。详情中的执行过程可以展开或收起。顶部菜单还保留“保存本次流程”、重新生成和清空对话等操作。答复的“查看依据”默认折叠，重要警告、错误和任务恢复操作仍直接显示。

这是应用内的命令行操作过程，不是其他手机应用的屏幕录像或浏览器画面。目前未实现浏览器视觉操作，工作区文件的通用导入/导出与预览入口也尚需完善。

## 实现与边界

NexusLiveExecution 管理可观察事件，NexusActivitySummary 根据是否存在实际命令显示一行状态或小直播，NexusLiveExecutionView 展示详情中的执行记录。聊天由引擎 onEvent / onCheckpoint 驱动步骤和工具结果；NexusLinuxTool 将 onStart / onStatus / onOutput 连接到 NexusLinuxRuntime 的真实 ObjC 行回调。手动终端复用执行记录视图。

行回调在主线程交付，操作ID与任务ID过滤旧回调。停止或结束后的直播对象拒绝新内容。checkpoint重复推送不会重复显示同一工具证据。

工作区容量扫描在后台线程执行并可取消；准备阶段尚未生成进程时，停止或进入后台也会阻止随后启动命令。执行状态区分准备、检查空间、准备工作区与实际运行。强退前已经登记的运行记录会在重启时标为意外中断，不自动重放命令。

为限制输出洪峰，ObjC 每条命令最多排入 200 次主队列更新，第 200 条显示截断提示；长行展示上限 1200 字符，完整 stdout/stderr 收集仍遵守原有每路 256 KiB 限制。滚动事件最多保留 60 条且合计不超过 16000 字符，较早内容移除并提示。`latestCommand` 在滚动事件之外另行保留最近命令，最多 1200 个脱敏字符；大量输出即使挤走原命令事件，也不会让小直播误退回普通状态行。开始新任务或重置时清空该命令引用。

已知当前连接密钥在直播对象中脱敏；直播不单独落盘，也不是完整审计日志。“详情”表示当前保留的过程，不保证包含已经因容量限制移除的早期输出。

新光球动画响应系统“减少动态效果”设置，并在应用非活跃时暂停。尚未完成真机功耗、发热或长时间帧率实测，不能据此宣称低耗能。

手动终端属于独立工作区，不能用它的截图证明真实模型已完成任务。自动化模型闭环使用可控模拟模型，工具和iSH实际执行；真实服务商模型效果必须另外验收。
