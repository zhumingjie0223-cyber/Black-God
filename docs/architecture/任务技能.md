# Black God 可复用任务技能升级

2026-09-09。本轮为聊天入口增加可编辑、可检索、可恢复历史版本的流程技能，并接入真实 Agent 工具回合。没有训练模型，也不把用户保存的流程标为已经验证的能力。

## 使用方式

“我的 → 任务技能”可以创建、编辑和删除技能。每个技能必须填写名称、适用条件、操作步骤和验收方法。

有步骤记录、成功工具证据且没有待确认警告的已回答任务，会在聊天页提供“把本次流程整理为技能”。这个入口仅生成可编辑草稿：取步骤标题和验收条件，不复制原始工具参数、脚本或输出。适用条件需要用户填写，保存不会自动执行。

## 智能执行接入

- 每次任务只提供当前技能目录中的ID、版本、名称和适用条件摘要；完整步骤不会全部加入初始请求。
- 新增 `skill_search` 和 `skill_read`。前者按名称/条件进行词面检索，后者按UUID读取当前版本的完整条件、步骤和验收方法；两个工具均只读。
- 技能内容作为参考资料返回。模型需要判断与当前目标是否匹配，使用已有工具检查实际状态，并重新验证本次结果。
- 文本工具模式与原生函数调用均接入；工具输出会进入任务证据和复核流程。读取技能不等于执行完成。
- 技能变更会停止使用旧快照的当前任务。继续时目录和读取工具使用当前版本；目录明确说明旧版本需要重新读取。
- 目录和被读取的内容会发给当前选择的模型。删除技能不会删除旧聊天、任务记录或已经发送的数据。

## 版本与存储

每个技能有稳定ID、递增版本号、保存时间，以及最多5个历史版本。恢复旧版本会生成一个新版本，保留恢复前的版本记录。同名冲突会报错，不会静默覆盖另一个技能。

由任务生成并经用户保存的技能保留来源任务ID和最多12个成功工具调用ID。这些ID提供来源线索，不代表流程经过独立评测；对应完整工具记录可能已不在当前有界任务摘要中。

最多30个技能。名称、条件、步骤、验收方法分别限制为60、500、1800、500字符。技能档案为应用支持目录的 `nexus-skills.json`，使用原子写入和iOS文件保护，总文件上限2MiB。写入失败不改变当前有效版本；文件损坏或格式不支持时停止提供技能并保留原文件。

界面测试覆盖新增、重启读取、编辑、恢复旧版本和删除。测试只使用本地隔离存储及受控模型响应，不证明真实模型在开放任务上的技能选择和执行质量。

## 仍未完成

当前技能由用户确认保存，不会自动从所有聊天中学习。没有技能独立效果评测、语义检索、自动质量评分或脚本幂等性保证。技能参考不增加操作授权，模型仍可能误判适用条件；需要通过真实任务评测检验效果。

本轮仅接入聊天入口；App Intents的技能、真实服务商API联调、真机界面问题与工业级验收仍待完成。没有上传、提交审核或操作用户手机。
