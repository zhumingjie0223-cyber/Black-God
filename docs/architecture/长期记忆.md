# Black God 长期记忆升级

2026-09-09。本轮将实际聊天入口的长期记忆改为用户明确保存、可更正和可删除的记录。

## 使用方式

在“我的 → 长期记忆”添加名称、内容和类型（偏好、约束、用户信息）。也可以长按自己发送的消息，选择“保存为长期记忆”，整理后保存。

例如名称为“项目名称”，内容为“Black God，不带数字”。以后修改同名记录会替换当前值并保持记录身份，不会将新旧两个值同时作为有效记忆引用。编辑时将名称改成另一条已存在记录的名称，会提示冲突，避免覆盖其他记录。

## 实际接入

- 当前长期记忆随聊天规划、执行与复核请求提供给所选模型，即使当前问题没有命中相同关键词。
- `memory_search` 在聊天中只检索当前有效的长期记忆，支持按名称或内容检索；仍为词面检索，不是语义向量检索。
- 不再自动把每条用户消息、模型回答保存为长期事实。旧版自动记录保留在“旧版自动记录（未启用）”中，可手动整理或删除，不默认用于回答。
- 保存、编辑、删除长期记忆会停止当前任务，防止它继续使用旧的记忆快照。下一次继续使用更新后的记录。
- 任务恢复时明确区分当前记忆与旧记忆；清空后会向模型明确说明当前清单为空。旧任务摘要和历史聊天仍可能包含原内容，优先级依赖上下文说明，不是对已发送数据的撤回。
- 每条记录有稳定ID、来源、创建/更新时间和类型。内容被标记为用户陈述，不能作为已经独立核实的事实或额外的操作授权。

## 存储与限制

最多50条长期记忆，名称和内容合计8000字符；单条内容最多1000字符。保存使用原子写入和iOS文件保护，写入失败不会修改内存中的有效值；损坏或超限文件会报错并保留，不会被静默覆盖。

记忆保存在应用支持目录的 `nexus-memory.json`。每次对话会将有效记忆发送给当前模型，因此界面明确说明用途，并提示不要保存API密钥。删除长期记忆不会删除历史对话、任务记录或已经发给服务商的数据。

本轮覆盖聊天入口，不包含App Intents的长期记忆接入、自动技能生成、模型训练、语义冲突判断或记忆版本回滚。用户仍需明确选择和整理要记住的内容。
