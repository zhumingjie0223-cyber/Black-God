# 枢语、技能演练与神枢互通

2026-09-09。本轮是应用内可运行的语言和演练基础，不是模型权重训练。

## 权威源与一致性

- 词汇源：shuyu/lexicon.js；原Python词汇引擎与词根表均未修改，旧编号不迁移。
- 新方言：shuyu/task_bridge.js与task_bridge.py；严格JSON字符串参数、完整语句检查、最多4条动作。标准质数原语两侧同义。
- 资源构建：tools/shuyu/bundle.py从源生成ios-app/ShuyuRuntime，记录SHA256；生成物内容或来源不同步，--check及check-sync会失败。
- iOS由JavaScriptCore运行固定资源，无JS网络桥和宿主文件对象；用户输入使用call参数，禁止输入拼接eval。
- 原nexuslang.js六回路解释器仍是独立组件；iOS本轮消费词汇与受限执行方言，没有把feel/think/grow文字当作意识或学习证明。

## 任务语言

```text
行：计算("12*3") → "36"
行：枢语("往返","神枢") → "true"
```

神枢模型可以调用shuyu查询词汇、编解码、造词、检索、质数和编译，也可用shuyu_execute执行程序。解析前检查大小，先对所有语句及工具可用性检查；工具子步骤逐项执行，失败或预期不符停止。每条shell最长10秒，程序最多4条，不开放递归shuyu_execute。工具结果保留succeeded与matched；没有预期时matched为空，不代表完成验证。

聊天操作直播能看到子工具结果；聊天检查点记录外层枢语操作的待完成状态与汇总结果。目前并非每个子动作独立持久化，进程强杀后的子动作完成情况可能未知；恢复不得自动重放这组操作。快捷指令已接枢语，但仍未全面接入聊天记忆/技能/恢复服务。

## 不断演练的实际机制

前台聊天页空闲时每分钟检查，距上轮至少15分钟才启动。每轮最多24样例，当前12样例。手动入口可立即运行；无模型API调用、无费用、仅合成资料与专用演练工作区。开始聊天先停止并等待演练清理，后台或切换功能页停止。

每条结果必须实际执行成功且与箭头预期一致。以技能版本、内容与样例计算指纹；只有当前指纹的连续完整通过轮次计入成绩，3轮为巩固门槛。新版本不继承，最新失败中断通过序列，取消和中断不能算通过。成绩保留最近30轮，本地原子写入；读写失败可见，损坏文件保留。结果作为有限范围参考送入聊天上下文。

这实现了持续本地演练和回归，不会自动修改模型权重、凭次数增强能力或自动改写技能。用户自建技能还没有自动生成可信样例，也未实现让真实模型不断生成新任务、提出技能修订、经过保留样例验证后晋级的闭环。应将此作为后续明确交付项。

## 运行空间

iSH使用可增长的宿主文件系统，不是固定容量磁盘镜像。新工作区的/bin、/lib等只读系统文件硬链接复用，/workspace与/tmp仍独立、以uid1000使用；已有工作区和用户文件不自动删除。测试覆盖共享系统文件无法修改、用户文件不串读。

预算1/2/4/8 GiB，首次按旧用量选择可容纳的档位；已配置的预算保持不变。空间统计按文件逻辑大小去重硬链接，不跟随外部符号链接；读取时消失的文件跳过，其他错误停止检查。执行前和约5秒间隔检查，缓存最多5秒，保留256 MiB手机空间。超预算、低空间或检查失败时停止命令；快速写入可能超调。不是硬配额，且逻辑大小不同于实际块占用。

本轮发现模拟器旧测试有429个工作区、约4 GiB文件。修复预算迁移与后续系统复制开销，未删除这些目录来掩盖问题。长期空间回收、文件导出和真正的文件系统配额仍需继续。
