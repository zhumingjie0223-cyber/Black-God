# Black God 沙箱主页

日期：2026-10-02。回应「沙箱都没有了」：把内置 Alpine Linux 工作区重新做成底部一等页面。

## 已实现

- 底部 Tab「沙箱」（原「创作」位）：执行开关、状态、终端、容量、工作区文件。
- 工作区文件：列表、导入（≤2 MiB）、导出、口令「确认清空工作区」。
- 沙箱终端使用独立 `sandbox` 工作区；聊天任务仍用 `chat` 工作区。
- 灵感草稿挪到「我的 → 灵感草稿」。

## 边界

- 不是浏览器可视操作沙箱。
- 不是硬磁盘配额；容量仍是软预算。
- 导入不支持任意系统目录挂载；宿主密钥不进沙箱。

## 验证

路径消毒单测本仓可跑；沙箱列表/导入依赖真机或模拟器 Linux 运行时，交 CI。
