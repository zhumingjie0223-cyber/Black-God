# Black God 沙箱强化

日期：2026-10-02。回应「不够强」。

## 已实现

- 单工作区硬配额：最多 200 文件、合计 32 MiB、单次写入 2 MiB；超限拒绝。
- 整镜像硬顶：用户预算与绝对上限 8 GiB 取较小值；执行前与导入时硬拒绝；沙箱页展示整镜像用量。
- 不可信脚本审计：删根、远程管道执行、格式化、反向外壳等高危模式默认拦截；助手可带口令「确认执行危险命令」单次放行；沙箱页可开「允许危险命令」。
- 工具：`workspace_list` / `workspace_read` / `workspace_write` / `workspace_delete` / `http_fetch`（仅 HTTPS，可关联网）。
- 工作区文件本机可视预览（HTML 禁脚本渲染 / 文本直显），不是远程浏览器点击自动化。
- 挂入聊天、快捷指令、技能演练与原生工具声明。
- 沙箱页展示工作区配额、整镜像硬顶、联网与危险命令开关。
