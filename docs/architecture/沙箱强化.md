# Black God 沙箱强化

日期：2026-10-02。回应「不够强 / 不够经验」。

## 已实现

- 单工作区硬配额：最多 200 文件、合计 32 MiB、单次写入 2 MiB；超限拒绝。
- 整镜像硬顶：用户预算与绝对上限 8 GiB 取较小值；执行前与导入时硬拒绝；沙箱页展示整镜像用量。
- 不可信脚本审计：
  - 先归一化（折叠空白/续行）再匹配；
  - 删根、远程管道执行、格式化、反向外壳等高危默认拦截；
  - 口令「确认执行危险命令」或沙箱页开关可放行，**放行仍留痕**；
  - 沙箱页展示最近审计事件（摘要，不含完整可复现攻击链）。
- 工具：`workspace_list` / `workspace_read` / `workspace_write` / `workspace_delete` / `http_fetch`。
- 导入走 `ensureWorkspaceReady`，不再假执行 `true`。
- 工作区文件本机可视预览（HTML 禁脚本 / 文本）。
- 挂入聊天、快捷指令、技能演练与原生工具声明。

构建号 20。
