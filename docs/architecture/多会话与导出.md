# Black God 多会话与导出

日期：2026-10-02。覆盖聊天入口的多会话隔离与用户导出，不操作用户手机，不发起真实模型请求。

## 已实现

- 会话索引 `nexus-sessions.json`，每个会话独立目录 `sessions/<id>/messages.json` 与对应任务恢复 `messages.agent.json`。
- 首次启动若仍有旧单文件 `nexus-conversation.json`，迁入第一个会话后删除旧路径。
- 新建、切换、重命名、删除；最多 40 个会话；至少保留一个。
- 导出 JSON（`blackgod.session.v1`）或纯文本，经系统分享发出。
- 清空仍只清当前会话；长期记忆、技能、自我状态不随会话删除。
- 单测自定义对话路径不启用会话库，保持原有单文件行为。

## 边界

- 不是完整事件日志或跨设备同步。
- 导出不含 API 密钥；消息正文仍可能含用户敏感内容。
- App Intents 仍走独立入口，尚未共享本会话列表。
- 本轮未做真机、真实服务商或商店上传。

## 验证

本地 Linux 环境无 Xcode，iOS 用例交 GitHub Actions。枢语 JS / Python 回归在本机构执行。
