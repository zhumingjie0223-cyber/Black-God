日期：2026-10-02。回应「升级太轻」：按工业级门槛推进入口一致性、长上下文与数据主权。

## 已实现

1. **共享任务服务** `NexusTaskService` / `NexusTaskBootstrap`  
   快捷指令与聊天共用记忆、技能、工具边界与检查点落盘；明确后台时限约束。

2. **上下文压缩** `NexusContextBudget.compact`  
   超预算时保留最近轮次，从更早消息提取首问与约束线索，写成可追溯摘要；摘要不能覆盖最新用户要求。

3. **全应用数据保险库** `NexusDataVault`  
   导出会话 + 长期记忆 + 技能清单（不含密钥）；清空全部会话需输入「确认删除」。

4. **跨会话检索**  
   会话列表可搜索全部会话消息并跳转。

5. **终端可见入口**（前序）与 **多会话隔离**（前序）保留。
